# GSAP (GreenSock Animation Platform) — Antigravity Standard Skill

GSAP is the primary animation platform for this project, utilizing the local suite inside `gsap-public/`.

- `gsap-public/minified/ScrollTrigger.min.js`

## Usage in Project
Always use GSAP and its plugins for UI transitions, scroll-driven timelines, interactive typography, and draggable components.
